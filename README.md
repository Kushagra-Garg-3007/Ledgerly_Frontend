# Ledgerly Frontend (Starter)

Clean starter setup for a finance dashboard app using React + Vite + JavaScript.

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS (via `@tailwindcss/vite` plugin)
- React Router (`react-router-dom`)
- Axios

## Installed Dependencies

- `react-router-dom`
- `axios`
- `tailwindcss`
- `@tailwindcss/vite`

## Setup Commands

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```
